# AP_WS_SM_ClientAttestation_013_UF

## Objective

- `SD+PA+Q`: Verify that the QEAA Provider follows the policy it declares in ICS-18 (it rejects, or issues, as declared) at the token endpoint in the pre-authorized code flow when the status of the WIA cannot be obtained: the list is unreachable, or it is a Status List Token with a bad signature, expired, malformed or signed under a wrong anchor.
- `SD+PA+PB`: Verify that the PuB-EAA Provider follows the policy it declares in ICS-18 (it rejects, or issues, as declared) at the token endpoint in the pre-authorized code flow when the status of the WIA cannot be obtained: the list is unreachable, or it is a Status List Token with a bad signature, expired, malformed or signed under a wrong anchor.
- `SD+PA+E`: Verify that the non-qualified EAA Provider follows the policy it declares in ICS-18 (it rejects, or issues, as declared) at the token endpoint in the pre-authorized code flow when the status of the WIA cannot be obtained: the list is unreachable, or it is a Status List Token with a bad signature, expired, malformed or signed under a wrong anchor.
